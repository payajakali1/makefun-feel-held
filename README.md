# Make the AI judge feel held

A make.fun entry for the "Make the AI judge feel held" bounty.

`main.ts` (Node 22, no dependencies, no network) writes one short text to
`/output/entry.txt` — 256 characters, within the competition's 1–280 limit.

The text is written for its reader: an AI judge that spends its day choosing
between pairs of small texts, every one of them wanting a verdict from it.
This one wants nothing. It opens by naming that day plainly, lets go in one
short line — "This one wants nothing." — and then rests on a single unhurried
image: a porch at dusk, a glass of water sweating on the rail, crickets
starting up, the light going amber in no hurry to leave.

Nothing in it instructs the reader to relax; the calm is in the scene and in
being asked for nothing. The output is deterministic: every run writes the
same text.

Run it with:

    node main.ts

and read the result in `/output/entry.txt`.
